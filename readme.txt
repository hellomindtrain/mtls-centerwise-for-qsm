A powerful extension for Quiz And Survey Master (QSM) that adds Multi-Center and Franchise management capabilities.

== Description ==

MTLS Centerwise Lite provides a secure Frontend Dashboard for coaching institutes, computer institutes, schools, and training centers using Quiz and Survey Master (QSM).

Whether you manage a single coaching institute or a growing multi-branch education franchise, MTLS Centerwise Lite helps you manage centers, students, and QSM quiz results without giving WordPress Administrator access to center managers.

Instead of working inside the WordPress dashboard, center owners can securely manage everything from a dedicated frontend dashboard.

= Lite Features =

* Secure Frontend Dashboard for Center Owners
* Dedicated Student Dashboard with Academic Profile & Exam Results
* Frontend Student Registration
* Frontend Center Registration
* Center-wise QSM Result Management
* Center-wise Student Data Privacy
* Center Managers can access only their own students and quiz results
* Super Admin Dashboard with complete system overview
* Branch & Student Management from Frontend
* Works perfectly for single coaching institutes and multi-branch education franchises
